# Prática de Git

Repositório de prática da disciplina Ciência de Dados Aplicada ao Direito I.

Faça um fork para a sua conta, clone o seu fork e trabalhe nele. Nada do que você enviar ao seu fork altera este repositório.

## O que tem aqui

`prazos.py` tem a função `prazo_em_dobro`, que recebe um prazo em dias e devolve o dobro, e uma linha que mostra o dobro de 15 dias.

## Como rodar

No terminal, dentro da pasta do repositório:

```
uv run prazos.py
```

O programa mostra `30`.
